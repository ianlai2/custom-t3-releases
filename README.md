# custom-t3 releases

Windows installers for a private fork of [T3 Code](https://github.com/pingdotgg/t3code) that adds
a context tracker and automatic session handoff.

This repository holds only release builds and their update manifests, which the installed app
checks for updates. The source lives in a private repository.

Install the latest `T3-Code-*-x64.exe` from [Releases](../../releases/latest). The installer is
not code-signed, so Windows SmartScreen asks before running it. Later versions install through
the app's own updater.
